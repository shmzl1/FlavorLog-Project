# 大模型（豆包 ARK）配置说明

本项目多模态识别功能（视频录入食物 / 冰箱扫描）接入了字节跳动的**豆包大模型（ARK 平台）**。  
API Key 属于敏感信息，**不能提交到 GitHub**，每位开发者需要在本地 `.env` 文件中自行配置。

---

## 一、获取 API Key

直接用 **项目负责人** 共享的 API Key，不需要自己在控制台创建。

---

## 二、配置步骤

### 1. 确认 `.env` 文件存在

进入 `backend/` 目录，确认有 `.env` 文件：

```bash
# 如果没有，从模板复制一份
cp backend/.env.example backend/.env
```

### 2. 填写大模型相关配置

用任意文本编辑器打开 `backend/.env`，找到 LLM 配置区块，填入以下内容：

```dotenv
# =========================
# LLM 配置 —— 豆包 ARK 多模态大模型
# =========================
LLM_PROVIDER=ark
LLM_API_KEY=<组长发的API>

LLM_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
LLM_MODEL=doubao-seed-2-0-pro-260215
LLM_TIMEOUT_SECONDS=120
```

| 字段 | 说明 |
|------|------|
| `LLM_PROVIDER` | 固定填 `ark` |
| `LLM_API_KEY` | 向负责人索取，格式 `ark-xxx...` |
| `LLM_BASE_URL` | ARK OpenAI 兼容接口地址，无需修改 |
| `LLM_MODEL` | 豆包多模态视觉模型，无需修改 |
| `LLM_TIMEOUT_SECONDS` | 请求超时秒数，默认 60 |



## 四、安全须知

- `.env` 文件已在 `.gitignore` 中，**永远不会被提交到 GitHub**。
- 请勿将 API Key 粘贴到代码文件、PR 描述、Issue 评论或聊天记录截图中。
- 若 API Key 泄露，立即在 [ARK 控制台](https://console.volcengine.com/ark) 将其禁用并重新生成。
