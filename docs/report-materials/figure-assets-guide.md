# Figure Assets Guide

以下内容用于统一整理项目文档中的截图、图注和插图放置说明，便于不同类型的报告复用。

## 建议的截图分类

- 分工与角色
- 需求条目
- 设计图与接口流程
- 关键代码片段
- 版本管理记录
- 质量检查结果
- 测试用例与缺陷记录
- 回归验证结果

## 推荐命名方式

- `fig1-role.png`
- `fig2-requirements.png`
- `fig3-design.png`
- `fig4-code.png`
- `fig5-git-log.png`
- `fig6-quality-check.png`
- `fig7-test-cases.png`
- `fig8-bug-list.png`
- `fig9-regression.png`

## 推荐记录字段

每张图建议附带以下信息：

- 图文件名
- 图中内容
- 插入正文的位置
- 图注文本

## 图注编写建议

- 图注尽量简洁，直接描述截图内容
- 如果截图中需要突出某一块区域，建议在图中框出后再插入正文
- 图注格式建议统一，例如“图 2-4 Git 提交记录”
