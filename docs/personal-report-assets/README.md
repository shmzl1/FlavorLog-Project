# Personal Report Assets

这个目录用于整理焦思源个人项目总结报告的附件素材，便于后续提交、截图和归档。

## 目录用途

- 汇总个人总结报告中需要插入的截图与图注
- 记录截图来源，避免后续补材料时遗漏
- 保留测试相关的补充图，例如控制流图、缺陷记录、冒烟回归结果

## 当前建议收集的材料

1. 计划书分工截图
2. 软件设计阶段汇报人截图
3. 需求文档中与菜单扫描、赛博冰箱、食谱推荐相关的条目截图
4. 软件设计文档中与本人负责模块相关的接口或流程图截图
5. Git 提交记录截图
6. 实验 5 黑盒测试用例执行结果截图
7. 控制流图与圈复杂度截图
8. 缺陷记录表截图
9. 冒烟脚本通过截图

## 使用建议

- 每张截图统一命名，便于在 Word 中插图和在 Git 中追踪
- 截图后可在本目录新增 `images/` 子目录集中保存
- 图注建议与正文章节编号保持一致，例如“图 2-4 Git 提交记录（本人提交）”
